## 📖 프로젝트 소개

Spring Boot를 이용하여 회원가입, 로그인(JWT), 사용자 관리, 세금계산서 관리를 구현하는 프로젝트입니다.

향후 AI 기능과 자동화를 추가하여 세무 업무를 쉽게 처리하는 것을 목표로 합니다.

---

## 🛠 기술 스택

- Java 17
- Spring Boot
- Spring Security
- JWT
- JPA
- MySQL
- Git
- GitHub
